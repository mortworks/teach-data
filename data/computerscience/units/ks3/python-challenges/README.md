# KS3 Python Challenges

This is a structured library of Python exercises for Key Stage 3.
Source exercises live in **YAML** files under `exercises/`.
Outputs for different environments are generated into `outputs/`.

- `exercises/` → atomic YAML challenges
- `outputs/idle/` → .py starter files
- `outputs/jupyterlite/` → .ipynb notebooks
- `outputs/hugo/` → markdown pages
- `tools/` → scripts for building outputs
